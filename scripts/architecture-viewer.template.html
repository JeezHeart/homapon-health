Hardware and Software Requirements of the Proposed System

Before using the system at the health center, check the computer, internet connection, printer, staff accounts, and online services. The list below is a planning guide, not a promise that every device will work.

AreaBasis for this system
Health-center computerA desktop or laptop with an internet browser, keyboard, and a screen staff can read comfortably. Test the actual device.
Internet connectionNeeded to sign in, use saved records, and send approved text reminders. This diagram collection can be read offline.
PrinterOptional for printed child records. Staff can also save a PDF instead of printing.
Website and record servicesOnline services keep the website available, check staff access, and store records. Render is selected for the main program, but deployment is deferred.
Text-message serviceRequires an approved account and sending setup. Staff must check unclear sending results before trying again.
Experimental Record ReviewRuns inside the website using a saved model and nine recorded vaccine dates. It suggests date patterns for staff to check; it does not diagnose health. Training the model is separate from daily use.
Diagram editingOpen the editable download in draw.io. Install Courier New on the device to keep the same font.
